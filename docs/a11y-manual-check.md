# בדיקת נגישות ידנית

הבדיקה האוטומטית (axe, WCAG 2.2 AA, מקלדת, רוחב 320px) עוברת. מה שנשאר דורש אדם. כ־20 דקות.
כשהכול עובר: לעדכן ב־`accessibility.html` את "בדיקה ידנית מלאה עם קוראי מסך עדיין לא הושלמה" ואת תאריך הבדיקה.

## מקלדת בלבד (בלי עכבר)
- [ ] דף הבית: Tab עובר על כל הבחנים, הסיכומים והפוטר, והפוקוס תמיד נראה.
- [ ] בוחן: Enter מתחיל, 1–4 בוחרים, S מדלג, Enter ממשיך, עד מסך הסיום.
- [ ] תפריט נגישות: נפתח ב־Enter, Esc סוגר ומחזיר את הפוקוס לכפתור.
- [ ] סיכום: כפתור ההדפסה נפתח במקלדת.

## קורא מסך (NVDA ב־Windows או VoiceOver ב־Mac/iPhone)
- [ ] הדף נקרא בעברית (לא באנגלית עם מבטא).
- [ ] בתחילת בוחן ואחרי "הבא": נקראת השאלה החדשה.
- [ ] אחרי תשובה: נשמע "נכון!" / "לא נכון." עם כפתור "הבא", ובתשובות: "תשובה נכונה" / "התשובה שבחרת, שגויה".
- [ ] מספרים ומונחים באנגלית (‎PR‎, ‎afterload‎) נקראים בסדר הנכון.
- [ ] בניווט לפי כותרות (H ב־NVDA, VO+⌘H) מבנה הדף הגיוני.

## תצוגה
- [ ] זום 200% בדפדפן: אין גלילה אופקית ושום טקסט לא נחתך.
- [ ] בטלפון: כל הכפתורים נוחים ללחיצה, גם במצב לרוחב.
- [ ] Windows "ניגודיות גבוהה" (Forced colors): הכפתורים והסימונים עדיין נראים.
